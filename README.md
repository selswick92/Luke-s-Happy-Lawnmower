# Luke's Happy Lawnmower 🚜🌿

A bright, forgiving, single-file HTML5 Canvas lawn mowing simulator built for a 4-year-old. Designed to run smoothly in any browser or as a full-screen Home Screen web app on an iPad—with zero external images or audio files required.

## Features
- **Husqvarna Orange Riding Mower:** Custom top-down HTML5 Canvas lawn tractor with a side-discharge deck, tractor tires, headlights, steering wheel, and gentle driving wobble.
- **Kid-Friendly Controls:** Tap or drag anywhere on the grass to drive, use the optional floating directional pad, or steer with keyboard arrow/WASD keys.
- **Built-In Web Audio Effects:** Synthesized mower purr, grass-cutting pops, flower/star chimes, playful obstacle boings, and a victory fanfare (with a mute toggle).
- **Personalized Start Screen:** Includes a local tap-to-add photo frame (saved privately on the device via `localStorage`) and a one-tap HTML export option.
- **iPad Home Screen Ready:** Configured with full-screen viewport metadata, safe-area padding, anti-zoom touch handling, and a custom-generated app icon.
- **Forgiving Game Loop:** Slow, relaxed pacing with a live score counter, mowing progress bar, and an automatic confetti celebration at 90% mowed.

## Tech Stack
- **HTML5 Canvas** (graphics & animations)
- **CSS3** (responsive full-viewport layout & UI)
- **Vanilla JavaScript** (game loop, collision detection, & `localStorage`)
- **Web Audio API** (synthesized sound effects)

## How to Play
1. Open `index.html` in any modern web browser, or visit the live GitHub Pages link.
2. Tap **Start Game** to wake up the audio and begin mowing.
3. Drive over the tall grass, collect flowers and stars, and watch out for the sleeping puppy!
